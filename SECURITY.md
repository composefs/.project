# Security Policy

## Reporting Security Issues

The composefs maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/composefs/composefs/security/advisories/new) form.

For more details, see the [composefs security policy](https://github.com/composefs/composefs/blob/main/SECURITY.md).
